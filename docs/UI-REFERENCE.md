# مرجع رسمی UI/UX برجینو

## مرجع اصلی

فایل مرجع رسمی طراحی رابط کاربری پروژه:

`docs/design-reference/nextable-dashboard.html`

این فایل HTML مرجع اصلی برای طراحی و پیاده‌سازی UI/UX برجینو است.

### قانون استفاده

- تغییرات UI/UX صفحات باید تا حد امکان با این مرجع هماهنگ باشند.
- ساختار Layout، Sidebar، Header، کارت‌ها، فاصله‌ها، رنگ‌ها، تایپوگرافی، نمودارها و رفتارهای نمایشی این فایل مبنای تطبیق هستند.
- این فایل **Design Reference** است و به‌خودی‌خود صفحه عملیاتی نهایی محسوب نمی‌شود.
- در صورت وجود اختلاف بین Mockup و نیازمندی‌های عملکردی پروژه، عملکرد واقعی و مشخصات فنی پروژه باید حفظ شود و ظاهر تا حد امکان با Reference هماهنگ شود.
