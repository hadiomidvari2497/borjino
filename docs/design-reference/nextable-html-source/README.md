# مرجع HTML قالب Nextable

این پوشه نسخه‌ی استخراج‌شده‌ی HTMLهای موجود در فایل `nextable.zip` است که به‌عنوان **مرجع طراحی و UX پروژه برجینو** نگهداری می‌شود.

## منبع

- فایل مرجع: `nextable.zip`
- تعداد HTMLهای استخراج‌شده: **158 فایل**
- دو تم موجود در منبع: `light/` و `dark/`
- ساختار و نام فایل‌ها تا حد امکان مطابق بسته‌ی اصلی حفظ شده است.

## نکته مهم

این فایل‌ها **مرجع طراحی و UX** هستند و قرار نیست مستقیماً جایگزین صفحات PHP برجینو شوند. هنگام پیاده‌سازی UI، ساختار صفحه، فرم‌ها، جدول‌ها، کارت‌ها، مودال‌ها، ناوبری، RTL، فاصله‌گذاری و الگوهای تعاملی باید بر اساس همین منبع بررسی شوند.

برای جلوگیری از تغییر ناخواسته‌ی سورس اصلی، HTMLها در 16 فایل متنیِ بخش‌بندی‌شده ذخیره شده‌اند. ابتدای هر بخش با نام دقیق فایل اصلی مشخص شده است، مثلاً:

```html
<!-- ===== SOURCE: light/index.html ===== -->
```

در نتیجه هر 158 فایل HTML در این مرجع قابل بازیابی و مقایسه با نسخه‌ی اصلی هستند.

## دسته‌های مهم برای توسعه برجینو

نمونه‌های مهم موجود در بسته که برای پیاده‌سازی پنل مدیریت برجینو کاربرد مستقیم دارند:

- `index.html` — داشبورد
- `login.html` — ورود
- `basic-form.html` / `advanced-form.html` — فرم‌ها
- `data-table.html` — جدول داده
- `basic-cards.html` / `image-cards.html` — کارت‌ها
- `alerts.html` / `badge.html` — اعلان و وضعیت‌ها
- `modal.html` / `dropdown.html` — تعاملات
- `datepicker.html` / `advanced-form.html` — ورودی‌های تاریخ و فرم
- `invoice.html` — الگوی اسناد مالی
- `profile.html` — پروفایل
- `settings.html` — تنظیمات
- `users.html` / `user-profile.html` — مدیریت کاربران
- `error.html` و صفحات خطا — وضعیت‌های خطا

> فهرست بالا صرفاً برای دسترسی سریع است؛ مرجع کامل شامل تمام 158 HTML استخراج‌شده است.

## اصل استفاده در پروژه

`docs/مشخصات-فنی-سامانه-برجینو.md` مرجع **نیازمندی‌های فنی و عملکردی** است و این پوشه مرجع **طراحی و UX** است. در صورت توسعه یا اصلاح رابط کاربری، این دو مرجع باید مبنا قرار گیرند.
