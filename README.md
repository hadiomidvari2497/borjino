# برجینو (Borjino)

سامانه مدیریت ساختمان — پروژه در حال توسعه بر اساس سند مشخصات فنی و نیازمندی‌های برجینو.

## وضعیت فعلی
- [x] تحلیل اولیه نیازمندی‌ها
- [x] طراحی اولیه دیتابیس و روابط
- [x] تعریف قالب خام UI با الهام از قالب Nextable ارسالی
- [x] تدوین نقشه راه و وضعیت قابل پیگیری برای توسعه‌دهندگان
- [ ] راه‌اندازی Backend
- [ ] راه‌اندازی Frontend عملیاتی
- [ ] پیاده‌سازی احراز هویت و RBAC
- [ ] پیاده‌سازی مدیریت ساختمان/بلوک/واحد
- [ ] پیاده‌سازی اعضا و قراردادها
- [ ] پیاده‌سازی موتور شارژ
- [ ] پیامک، تنظیمات، گزارش‌ها و تست نهایی

## مستندات
- `docs/database/schema.sql` — اسکیمای PostgreSQL و کلیدهای اصلی/فرعی
- `docs/roadmap.md` — مسیر راه، وضعیت هر فاز و معیار تکمیل
- `template/README.md` — راهنمای قالب خام و تصمیم‌های UI
- `template/index.html` — پوسته اولیه RTL برای برجینو

## منبع نیازمندی
سند «مشخصات فنی و نیازمندی‌های سامانه مدیریت ساختمان برجینو» مبنای تحلیل این مرحله است. قالب UI نیز از فایل Nextable ارسالی پروژه انتخاب شده است.

> اصل توسعه: هر قابلیت قبل از ورود به فاز بعد باید مستند، قابل تست و دارای وضعیت مشخص در Roadmap باشد.
