# قالب خام برجینو

این پوشه baseline رابط کاربری برجینو است.

## منبع
فایل ZIP ارسالی `Nextable` شامل نسخه‌های RTL و Light/Dark است. به‌دلیل اینکه فایل فعلی یک قالب HTML آماده است، در این مرحله یک پوسته خام مستقل ایجاد شده تا معماری کسب‌وکار به قالب گره نخورد.

## اصول UI
- RTL و فارسی‌محور
- آماده برای Light/Dark
- Sidebar ماژولار
- Header/Topbar
- کارت‌های KPI
- جدول داده
- Responsive baseline

## مرحله بعد
در زمان تثبیت stack فرانت‌اند، assets و کامپوننت‌های منتخب Nextable به componentهای واقعی منتقل و Design System برجینو روی آن سوار می‌شود.
